Postgres Database Endpoint

Admin-managed — the shared server every user connects to. Each user sets their own database, schema, username, and password under Settings → My Connection → Postgres.

My Pathway Collection

Your own local directory of RNEF / .graph.json pathway files, indexed for File → Pathways search commands. This is personal to your account — each user points at (and indexes) their own collection. Indexing walks the directory recursively and can take a while for a large collection — it runs in the background; the app remains usable while it works.

Two kinds of entries: (1) one specific node — fill in both Name (its exact Name) and Label (e.g. "BRCA1" / "Protein"). (2) a whole category of nodes — put the label(s) in the Name field instead (e.g. "SmallMol" or "Protein|FunctionalClass|Complex") and leave Label blank.
